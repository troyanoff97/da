# ДА. — Искусство соглашаться

Статический сайт для отправки утвердительного ответа. Для работы нужны только файлы в этой папке. Все медиа размещаются вместе с сайтом.

## Локальный запуск

В этой папке выполните:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Откройте [сайт](http://127.0.0.1:8000/) или [пример ссылки с вопросом](http://127.0.0.1:8000/?q=%D0%A2%D1%8B+%D1%81%D0%BE%D0%B3%D0%BB%D0%B0%D1%81%D0%B5%D0%BD%3F). HTTP нужен для проверки копирования и системного меню отправки в условиях, близких к размещению.

## Размещение

1. Загрузите содержимое папки на любой статический HTTPS-хостинг, сохранив структуру.
2. В `index.html` замените значение `og:image` абсолютным публичным HTTPS-адресом файла `assets/og-preview.jpg`.
3. Откройте сайт по публичному адресу и проверьте новое превью, отправив ссылку в мессенджере. Ранее отправленные ссылки могут сохранять старое превью в кеше.

Персональный вопрос находится в адресе ссылки. Генератор открывается кнопкой с цепочкой. Сайт не отправляет введённые значения никакому отдельному API.

## Проигрывание

«Запустить со звуком» запускает 32-секундный монтаж. При недоступности аудио сцены идут по внутренней шкале. При открытии сайт пробует запустить фоновую музыку. Если браузер требует взаимодействия, кнопка «Запустить со звуком» включает дорожку и фильм одним нажатием. Кнопка «Звук» доступна при прокрутке и управляет музыкой и эффектами. Во время показа клавиша Escape ведёт к финалу. Авторство и лицензия приведены в [LICENSES.md](LICENSES.md).
