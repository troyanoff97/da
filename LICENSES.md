# Музыка и медиа

**Clash Defiant** — Kevin MacLeod (incompetech.com), ISRC USUAN1600003.  
Лицензия [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/).  
[Страница композиции](https://www.incompetech.com/music/royalty-free/index.html?isrc=USUAN1600003).

В `assets/hero-theme.mp3` используется 32-секундный фрагмент произведения с плавным началом и концом. Веб-презентация добавляет отдельные звуковые эффекты поверх записи.

Эффекты в `assets/sfx/` синтезированы для проекта.  
Портрет предоставлен заказчиком. Из него подготовлены оптимизированное изображение, слой с мягкой маской и превью для мессенджеров.
